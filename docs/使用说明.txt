Co_cofe 建模看图工具 · 使用说明
================================

一句话：把图纸永远钉在建模软件上方，可调大小、可调透明度，
          点它拖它都不会打断你正在做的建模操作。

一、标题栏按钮
--------------
  ?      打开这份使用说明
  —      最小化到托盘（按 Ctrl+Alt+O 可以再叫出来）
  □      最大化 / 还原（双击标题栏同效）
  ✕      退出程序
  标题    显示当前图纸文件名；拖动标题栏也能移动窗口

二、欢迎页
----------
  没有打开图纸时显示欢迎页，底图是同目录下的 welcome.jpg，
  想换成自己的图，直接替换这个文件即可（png 也行，改名 welcome.png）。
  右下角署名「冷咖啡制作 / Co_cofe」是直接画上去的，改程序里的文字才能改。

  软件图标来自 logo.png（已生成 app.ico 并编进 exe）。
  想换图标：用 logo.png 重新生成 app.ico，再用
  csc /win32icon:app.ico 重新编译即可。

三、鼠标操作
------------
  移动窗口        左键拖动画面，或拖动标题栏
  改窗口大小      拖动窗口四条边 / 四个角（图片自动跟着缩放）
  放大 / 缩小     滚轮（1x 为适应窗口，最大 10x）
  复位缩放        双击画面（不在标题栏上）
  平移放大后的图  Ctrl + 左键拖动
  透明度          Ctrl + 滚轮无级微调（5% 一档）
  切换多张图      Shift + 滚轮

四、右键菜单
------------
  使用说明…       打开这份说明（和标题栏的 ? 一样）
  打开图纸…       选择图片文件
  上一张 / 下一张  只在拖入了多张图时可点
  点击穿透        开启后鼠标直接点到底下的建模软件
  复位缩放
  透明度 85%　(点击切换)   每点一次在 100/90/80/…/20% 之间循环
  隐藏 / 退出

五、快捷键（全局，建模软件有焦点时也有效）
------------------------------------------
  Ctrl + Alt + O   显示 / 隐藏小窗
  Ctrl + Alt + P   切换点击穿透

六、支持的文件
--------------
  图片：png / jpg / jpeg / bmp / gif / tif / tiff
  拖进窗口即可打开；也可以一次拖入多张图片或整个文件夹。
  PDF 暂不支持——需要 PDF 的话，可以先用阅读器截图或导出成图片。

七、适用软件
------------
  本工具与任何 CAD 都没有耦合，只是"置顶的看图窗口"，所以
  SolidWorks / CATIA / UG(NX) / Creo / Inventor / Fusion 全部通用。

八、几点设计说明
----------------
  · 窗口不抢焦点（WS_EX_NOACTIVATE）：点它、拖它，建模软件里的命令和
    键盘输入都不会中断，不用再点回主窗口激活。
  · 整窗半透明用分层窗口（WS_EX_LAYERED + LWA_ALPHA），图纸后面的模型、
    任务窗格都能透出来对照。
  · 置顶是 WS_EX_TOPMOST，主窗口最大化也压不住它。
  · 右键菜单是窗口内自绘的，不依赖系统弹出菜单，因此不会抢焦点。

九、已知限制
------------
  · 只支持图片，不支持 PDF。
  · 透明度作用于整个窗口（含边框），不能只让图纸白底变透明。

十、配置文件
------------
  %APPDATA%\SwPin\state.txt  记录窗口位置、大小、透明度、上次打开的图。
  删掉该文件即恢复默认。

十一、关于本说明
----------------
  程序目录下的「使用说明.txt」会被优先读取，想改文字直接改那个文件；
  文件不存在时用程序内置的同一份文本。
