Co_cofe 建模看图工具  v1.0.0
=============================

【怎么开始】
  绿色版：双击 Co_cofe建模看图工具.exe
  安装版：双击安装包，按提示下一步

  然后把 JPG / PNG 图纸直接拖进窗口，就能用了。


【它解决什么问题】
  建模时想看图纸，就得切窗口、缩放、再切回来，来回折腾。

  这个工具把图纸钉在所有窗口最上层，可调大小、调透明度，
  而且不抢焦点——点它、拖它，SolidWorks / CATIA / UG / Creo 里的
  命令和键盘输入都不会中断，不用再点回主窗口。


【常用操作】
  拖动画面 / 标题栏      移动窗口
  拖四条边、四个角        改窗口大小（图纸自动跟着缩放）
  Ctrl + 滚轮            调透明度（5% 一档）
  滚轮                   放大缩小（1x = 适应窗口，最大 10x）
  双击画面               复位缩放
  Ctrl + 左键拖          放大后平移图纸
  Ctrl + Alt + O         显示 / 隐藏
  Ctrl + Alt + P         点击穿透（鼠标直接点到建模软件上）
  右键                   菜单（使用说明 / 打开 / 透明度 / 穿透 …）
  标题栏 ?               完整使用说明


【运行要求】
  · Windows 10 / 11（依赖系统自带的 .NET Framework 4.x，一般都已安装）
  · 不联网、不装服务、不写注册表
    （只在 %APPDATA%\SwPin\state.txt 记一下窗口位置和透明度）
  · 免安装，删掉文件夹就卸载干净了


【注意】
  · 只支持图片格式（png / jpg / jpeg / bmp / gif / tif），不支持 PDF
  · 首次运行若被 SmartScreen 提示"未知发布者"，
    点「更多信息 → 仍要运行」即可
  · 被 360 / 火绒 拦截时选择放行：程序没有联网行为，也没有安装器
